# v8std — стандарты разработки 1С

Скилл обращается к публичному MCP-серверу v8std.ru (`https://ai.v8std.ru/mcp`) через скрипт
`scripts/v8std.py` (Python 3, только стандартная библиотека). Сервер только читает базу знаний:
он не запускает анализаторы, не смотрит проект и не меняет код.

## Вызов

Путь к скрипту — относительно папки этого скилла:

```bash
python "<папка скилла>/scripts/v8std.py" <команда> ...
```

| Задача | Команда |
|---|---|
| Найти правило по теме/вопросу | `search "текст" [--limit 10] [--types standard diagnostic fix pattern service] [--mode hybrid\|exact\|bm25\|semantic]` |
| Прочитать страницу целиком | `page <id\|алиас\|URL> [--body-limit 12000]` (1000–30000) |
| Связанные стандарты и диагностики | `related <id> [--relations standard diagnostic edt_check related] [--limit 10]` |
| Расшифровать коды диагностик | `diag "acc 1245" "АПК:361" "bslls:UsingModalWindows" ...` или по одному коду на строку в stdin |
| Сопоставить кусок кода со стандартами | `snippet --file proc.bsl [--language auto\|bsl\|sdbl] [--limit 10]` или код через stdin |
| Любой инструмент напрямую | `raw <tool> '<json-аргументы>'` |

`--full` перед командой (`v8std.py --full search ...`) возвращает ответ без сокращений
(с `score_details`, `match_reasons`, алиасами). Обычно он не нужен.

Идентификаторы страниц: стандарты — `std437`, диагностики — `acc:1245`, `bslls:UsingModalWindows`,
`v8cs:dont-use-modality-mode`. Подходят и URL вида `https://v8std.ru/std/703/`.

## Какой инструмент выбрать

1. **Есть коды из отчёта или из комментария-подавления** → `diag`. Это точнее поиска:
   код сразу сопоставляется с диагностикой и стандартом.
2. **Есть одна процедура или один запрос** → `snippet`. Передавай одну релевантную процедуру,
   не модуль целиком (лимит 12000 символов). Если фрагмент слишком большой, сокращай его, а не повторяй вызов.
3. **Известен номер или ссылка** → сразу `page`.
4. **Вопрос своими словами или неизвестный идентификатор** → `search`, потом `page` по лучшему `id`.
   Для неточных кодов и опечаток используй `--mode exact`, для перефразированных вопросов — `--mode semantic`.
5. **Нужно перейти от стандарта к диагностикам (или наоборот)** → `related`.

Обычная цепочка: `search` / `diag` / `snippet` → `page` по найденным id → ответ.

## Как отвечать пользователю

- Опирайся на текст страницы (`page`), а не только на `description` из поиска: описание обрезано.
- Если в ответе `body_truncated: true`, повтори `page` с большим `--body-limit` (до 30000),
  если обрезанная часть может быть важна.
- Давай ссылку на правило: `url` (v8std.ru), а если есть `source_urls`, то и первоисточник its.1c.ru.
- Указывай номер стандарта и пункт (`#std703`, п. 1), когда он есть в ссылке (`/std/703/#1`).
- Объясняй правило простыми словами и показывай, как исправить код пользователя.

## Чего не утверждать

- Совпадения из `snippet` — эвристические кандидаты, а не подтверждённые нарушения.
  Проверь код по тексту правила, прежде чем говорить «здесь нарушение».
- Пустой результат `snippet` или `search` не значит, что код правильный: значит лишь, что в базе нет совпадений.
- `unknown_codes` в `diag` означает «нет в этой базе», а не «такой диагностики не существует».
- Найденный код подавления (`// АПК:361-выкл`) сам по себе не оправдывает подавление.
- `score` — это ранг, а не вероятность.

## Конфиденциальность

Публичный сервер получает текст запросов и фрагменты кода. Не отправляй в `snippet` закрытый код
с секретами, паролями, строками подключения или персональными данными: замени их заглушками или
отправь только нужную часть. Если пользователь работает с конфиденциальным кодом, предложи
локальный сервер (ниже) или спроси разрешения перед отправкой.

## Локальный сервер (по желанию)

Если поднят локальный Docker-образ v8std (инструкция: https://v8std.ru/mcp/), задай адрес
через переменную окружения:

```bash
V8STD_MCP_URL=http://127.0.0.1:18766/mcp python scripts/v8std.py search "транзакции"
```

В PowerShell: `$env:V8STD_MCP_URL = "http://127.0.0.1:18766/mcp"`.

## Ошибки

- `Сервер недоступен` — нет сети или сервер лежит. Как запасной вариант прочитай Markdown напрямую:
  `https://v8std.ru/std/<номер>.md` или `https://v8std.ru/diagnostics/<анализатор>/<код>.md`.
- `Ошибка инструмента` — смотри текст: обычно превышен лимит или передан неверный аргумент.
