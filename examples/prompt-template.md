## Особенности testpilot
- Поля-перечисления: `choose_from_drop_list`/`select_option` могут не работать — вводи `input_text` с текстом представления значения.
- Ссылочные поля: выбирай через `start_choosing` + `choose_row` (`input_text` может не вызвать `ПриИзменении`).
- Окна авторизации внешних интеграций закрывай кнопкой «Отмена» (логин и пароль не вводить), затем повтори последний шаг.
- `read_fields` не принимает кнопки, видимость проверяй через `is_visible`. «Только просмотр» поля — через `is_readonly` и попыткой ввода.
- При таймауте диагностики: `disconnect` → `connect`, затем найди элементы заново и проверь, выполнилось ли последнее действие (например, «*» в заголовке окна); не выполнилось — повтори.
- Строка таблицы: `tc_table(action="goto_row", fields={"<заголовок колонки>": "<значение>"})` — ключ это видимый заголовок колонки, не имя элемента. Открыть строку — `change_row`; ответ `edit_state_unavailable` не значит отказ — проверь `get_active_window`.
- Окно «Непредвиденная ошибка» (`navigation_failed`, `ErrorWindow`): сначала `tc_app(action="get_current_error")` — текст и стек в `details` перенеси в отчёт, потом закрой кнопкой `OK`.
